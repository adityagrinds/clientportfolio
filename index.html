Ultrasonic Proximity
Alert System

An HC-SR04 ultrasonic sensor fires a 40 kHz pulse and times the echo. The Arduino converts that time into distance and lights a warning LED the moment an object crosses the threshold — the same principle behind parking sensors.

d = (t × 0.0343) / 2012 cm

Analog PWM
LED Dimmer

Turn the knob, change the light. A potentiometer feeds a 10-bit analog reading (0–1023) which is mapped to an 8-bit PWM duty cycle (0–255) — real-time closed-loop control between a human input and a physical output.
